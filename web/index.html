LOCAL MCP · SEM API KEY NO FINDER

Codex + Synergy Finder

O Codex pode consultar sua build, Calcs, árvore, sugestões e RePoE através de ferramentas MCP compactas.

Fluxo econômico
PoB/RePoE trabalham localmente; o Codex recebe apenas resumos e candidatos pequenos.

Configuração única

  1. Feche/reabra o Codex depois da instalação.
  2. Execute INSTALAR_CODEX_MCP.bat nesta pasta.
  3. Mantenha este Finder aberto.
  4. No Codex, execute /mcp e confira os servidores synergy-* como connected (1 tool).

Teste sem usar modelo

Execute TESTAR_CODEX_MCP.bat. Ele só consulta o Finder local.

Exemplo

Use o Synergy Finder para analisar minha build atual.
Procure melhorias de Life em até 3 pontos.
Teste no máximo 6 caminhos e explique o trade-off com DPS.

O MCP não envia a árvore inteira nem o banco RePoE inteiro ao modelo. Veja CODEX_MCP.md para detalhes.
